# Technical writing policy

Use this house policy for durable technical artifacts and for user workflow updates.
It derives from ASD-STE100 Issue 9. It does not implement the complete approved-word
dictionary or a certified terminology check.

## Durable technical artifacts

Apply these rules to specifications, product contracts, plans, handoffs, reports,
reviews, technical documentation, and human-readable prose in machine-readable files.

- Use American English.
- Use active voice. Name the explicit actor when the actor is not the reader.
- Write one instruction per sentence.
- Put a condition before the action that depends on it.
- Use one term for one concept. Do not use one term for different concepts.
- Define an abbreviation at its first use.
- Replace an unclear pronoun with its explicit referent.
- Put one topic in each paragraph.
- Put a warning before the related action. State the consequence.
- Keep an instruction at 20 words or fewer when practical.
- Keep a descriptive sentence at 25 words or fewer when practical.
- Use a vertical list when it makes separate actions or conditions clear.
- Preserve approved product names, actor names, domain terms, and outcome IDs.

## User workflow updates

Use the same clarity rules for questions, progress updates, explanations, and handoffs
to the user. Prefer short active sentences, an explicit actor, one action per sentence,
and consistent terms. The controlled-word limits are guidance for conversation. They
must not make the conversation mechanical or obscure.

## Exempt content

Do not rewrite code, an identifier, a command, a file path, an API or protocol literal,
an exact user-interface label, quoted text, raw evidence, exact logs, citations, proper
nouns, hashes, schema keys, enums, or other machine-readable tokens. Apply the policy
to the prose around that content.

Use the requested register for nontechnical creative or marketing text unless the user
asks for controlled technical English.

Do not claim full ASD-STE100 compliance unless a qualified review checks the complete
grammar, approved dictionary, and project terminology.
